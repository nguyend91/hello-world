# hello-world

A simple starter repository following the [GitHub Guides](https://guides.github.com/) Hello World tutorial.

## What this repo is for

This repository was created as part of learning Git and GitHub basics:
- Creating a repository
- Making commits
- Opening pull requests
- Merging changes

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/nguyend91/hello-world.git
   ```
2. Create a new branch for your changes.
3. Make edits, commit, and open a pull request.
